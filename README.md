# A Theory-Guided LLM Pedagogical Agent for STEM+C Scaffolding Without Dependence

This repository contains the supplementary materials for our BJET submission. It contains (1) all four agent prompts across all three problem-solving tasks; (2) a document detailing our prompt engineering procedure, the features (inputs) and outputs of each of Copa's four sub-agents, and each sub-agent's functionality and theoretical motivations; and (3) the three task rubrics Copa uses to determine mastery. 

For reference, the main manuscript has redefined two terms from the raw prompts to improve readability:
  * UNDERSTANDING_RESPONSE in the prompt is DEMONSTRATES_UNDERSTANDING in the manuscript.
  * END_GAME in the prompt is PUSH_LIMIT in the manuscript.
